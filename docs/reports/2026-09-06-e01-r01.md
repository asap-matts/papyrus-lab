## Ambiguità e ostacoli nelle istruzioni

1. **Stato iniziale del clone:** il repository era pulito ma su `main`, non su `e01-socio`, nonostante il piano dichiarasse il branch già predisposto. L'esecuzione si è fermata come richiesto; dopo istruzione esplicita del socio è stato creato il branch locale tracciando `origin/e01-socio`.
2. **Python iniziale insufficiente:** `scripts/e01_bootstrap_mac.sh` si è fermato con `STOP serve Python 3.11 o superiore (trovato Python 3.9.6)`. Il piano non includeva un comando preliminare per aggiornare una versione esistente troppo vecchia; il socio ha poi autorizzato esplicitamente l'installazione. Installato `python@3.12` 3.12.14 con Homebrew.
3. **Selezione di Python dopo l'installazione:** il `PATH` del processo Codex anteponeva `/usr/bin` a `/opt/homebrew/bin`; inoltre Homebrew colloca i collegamenti non versionati di `python@3.12` in `.../libexec/bin`. Lo script continuava quindi a scegliere Python 3.9.6. È stato necessario anteporre temporaneamente `/opt/homebrew/opt/python@3.12/libexec/bin` a ogni comando Python; nessun file del progetto è stato modificato.
4. **Installazione Kaggle incompatibile con PEP 668:** con Homebrew Python 3.12, il comando dello script `pip install --user --upgrade kaggle` è stato bloccato da `externally-managed-environment`. Lo script sopprimeva il dettaglio di `pip` e mostrava soltanto `STOP installazione della CLI Kaggle fallita`. Per proseguire dopo l'autorizzazione del socio è stata usata, solo per il bootstrap, la variabile `PIP_BREAK_SYSTEM_PACKAGES=1`, mantenendo `--user`; nessuna configurazione permanente è stata cambiata.
5. **Callback OAuth fuorviante nel browser:** dopo l'autorizzazione Kaggle il browser ha mostrato `ERR_CONNECTION_REFUSED` su `localhost:8244`, mentre il processo CLI aveva già ricevuto il callback e stampato `You are now logged in as [micheleghisa]`. Le istruzioni non spiegavano che la pagina di errore può comparire anche dopo un login riuscito.
6. **Verifica autenticazione poco chiara:** il comando obbligatorio `kaggle kernels list --mine --page-size 3` ha stampato `Not found` ma ha restituito codice 0; il bootstrap ha classificato l'autenticazione come attiva e le successive operazioni Kaggle sono riuscite. Il testo non distingue “nessun kernel trovato” da errore di autenticazione.
7. **Stato dataset transitorio:** il primo `datasets status micheleghisa/papyruslab-w035-labels` ha restituito `403 Forbidden`; la ripetizione prevista dal piano ha restituito `ready` senza altre modifiche.
8. **Rate limit esterno non assorbito dal preflight:** preflight v1 è fallito perché `hf download` non ha ritentato dopo il `429 Too Many Requests` di Hugging Face. Il piano permetteva esplicitamente il retry per cause esterne; dopo 209 s, preflight v2 è riuscito senza modifiche.
